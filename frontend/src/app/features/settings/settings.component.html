Modo producción oficial

Usa Meta WhatsApp Cloud API para operar como canal empresarial estable.

Aquí no existe QR de conexión: necesitas credenciales de Meta, Phone Number ID, token y webhook.

Ingresa el número que usará el bot (ej: 573001234567 con código de país, sin + ni espacios)

¿Se puede dejar igual para WhatsApp normal y Business?

No exactamente. QR y Meta Cloud API son dos métodos distintos.

Para desarrollo local puedes usar el QR. Para producción con WhatsApp Business oficial debes usar Meta Cloud API.

Recomendación: usa un número para pruebas por QR y otro número para producción en Meta. No conviene operar el mismo número en ambos métodos.

Checklist para producción con Meta Cloud API

Para producción, Orderly usa la Meta WhatsApp Cloud API. Necesitas:

  1. Una cuenta de Meta Business
  2. Registrar tu número en el portal de desarrolladores
  3. Obtener tu Phone Number ID y Access Token
  4. Configurar el webhook de Orderly en tu app de Meta

Por ahora puedes guardar tu número y usar el QR para hacer pruebas locales del bot.
